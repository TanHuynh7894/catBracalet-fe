# Cat Bracelet Frontend

This project was initialized with Vite + React and structured according to your requirements.

## 📂 Project Structure

- `src/assets/`: Static files (images, icons, etc.)
- `src/components/`: Reusable UI components
- `src/layout/`: Layout components (Header, Footer, Sidebar, etc.)
- `src/pages/`: Main application pages and route definitions
- `src/features/`: Feature-based modules (domain-specific logic)
- `src/hooks/`: Custom React hooks
- `src/context/`: React context providers for global state
- `src/redux/`: Redux Toolkit store, slices, and logic
- `src/services/`: API client and external service integrations
- `src/utils/`: Helper functions and utility classes

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## 🛠 Tech Stack

- **Framework**: React 18+
- **Build Tool**: Vite
- **State Management**: Redux Toolkit (Pre-installed)
- **Routing**: React Router DOM (Pre-installed)
- **Styling**: Vanilla CSS (Modern design)
